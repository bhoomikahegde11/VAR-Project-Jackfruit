# 🧵 Interactive Cloth Simulation (Three.js)

A simple physics-based cloth simulation built using **Three.js**, featuring:
- Realistic particle-based cloth physics
- Click-and-drag vertex interaction
- Constraint-based tearing behavior
- Smooth camera orbit controls (arrow key navigation)
